## 観測根拠の残し方

[observations.json](observations.json) はメソッド・パス・ステータス・レスポンスの型だけを保存する。`pageId` と `reqid` は調査中のMCPセッション内の参照番号であり、後日その番号だけで再取得はできない。

代表的な通信は以下で確認した。

| MCPページ／リクエスト | 内容 |
| --- | --- |
| page 4 / req 34（初回ホーム） | 未ログインのユーザー取得、401、`LOGIN_REQUIRED` |
| page 4 / req 343 | ログイン後のユーザー取得、200 |
| page 6 / req 20 | ジャンルからpackage取得、200 |
| page 7 / req 96, 97 | 課外チャプター／コース、200 |
| page 3 / req 349, 350 | 必修チャプター／コース、200 |
| page 9 / req 58 | 授業一覧の `base_id` 追加、200 |
| page 9 / req 98, 129 | 検索の `offset=0` → `20`、200 |
| page 8 / req 123 | フォーラムのカーソル追加、200 |
| page 10 / req 32, 42 | CSRF発行と学習イベント、201 |
| page 5 / req 304 | 通知既読化、204 |

大きい本文はMCP出力で切れる場合があった。その場合、すでに画面で観測したGET URLだけを、ログイン済みページの `fetch(url, {credentials: 'include'})` で再取得した。ブラウザ内で値を型に変換して返し、生の個人情報をファイルへ書き出していない。POST・PUTは再実行していない。

`shapeSource` の意味:

| 値 | 根拠 |
| --- | --- |
| `network_response` | `get_network_request` の応答本文 |
| `authenticated_get_replay` | 実際に観測したGETの再取得。形状はログイン後のもの |
| `earlier_network_response` | 保存済みの初期観測。未ログイン401のエラー構造 |
| `same_endpoint_other_limit` | 同じパス・modeの別limitで取得した構造。対象limitでの形状保証はしない |

`capture` が残っている項目は本文構造を確定していない。配列は先頭要素だけを採取したので、必修セクションの種類や授業状態による違いは、実装前に追加確認が必要。

## 閲覧に伴う更新も発生した

授業画面を開くと動画が自動再生され、`POST /v3/learning_events` が送られた。確認後に再生を停止した。通知一覧を開くと `PUT /v1/notices/{noticeId}/mark` が自動送信された。したがって、今回の閲覧には視聴履歴や既読状態の更新が伴う可能性がある。

フォーラム詳細はGETでも `views_count` を返すため、閲覧数が変わる可能性がある。GETだから状態が一切変わらないとは扱わない。初回案内を閉じる操作も行った。

HAR、Cookie、CSRF値、プロフィールの実値、成績の実値、他ユーザーの投稿本文、署名付き動画URLはリポジトリに保存していない。機械可読な記録も値を除いた型情報である。

## 未確認のAPIを推測で埋めない

初回は画面を閲覧して発生した通信を中心に記録した。追加の動画調査でコードから見つけた候補は、実通信と区別して動画ドキュメントに記載した。以下は引き続き未確認。

- ログイン処理全体、必要なセッションCookie、ログアウト。CSRFのクライアント内の期限判定・更新分岐はソースから追加確認済み。
- コース選択／解除、理解度更新、学習イベントの全種類と集計への影響。動画教材の再生位置保存は追加調査で確認済み。
- 解答・採点・レポート提出・再提出の成功通信と、定期テストのセッション。取得経路と配信コード上の送信候補は追加調査で確認済み。
- フォーラムの作成・返信・解決・編集・削除・添付ファイル送信。
- ライブ配信中のコメント、質問、挙手、クイズ、アンケート、WebSocketの通信仕様。
- 通知のページ送り、各一覧の終端条件、最大limit、レート制限、エラー一覧。
- 有料／無料や所属の異なるアカウントでの差。今回の単一セッションだけでは一般化できない。

次の調査では、対象機能を一つずつ操作し、変更前後の通信・状態を対にして記録するとよい。特に解答や提出のAPIは、提出が許可された練習用データで確認する。
